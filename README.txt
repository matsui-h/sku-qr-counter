# SKU QRカウンター（iPhone版）

## 機能
- iPhoneカメラでQRを連続読み取り
- QRの内容をSKUとして数量を+1
- 読み取り成功時にバイブレーション
- SKU別集計
- 誤読時の-1
- 読み取り履歴
- 日付別に端末内保存
- 集計CSV / 履歴CSV出力
- Safariからホーム画面に追加してPWAとして利用

## 重要
カメラ利用にはHTTPSで配信する必要があります。
このフォルダをそのままiPhoneの「ファイル」から開いても、カメラは動かない場合があります。

GitHub PagesなどHTTPSで公開できる場所にアップロードしてSafariで開き、
「共有 → ホーム画面に追加」で利用してください。

QRの内容はそのままSKU文字列としてカウントします。
